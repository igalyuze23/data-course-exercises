# Data Course Exercises

Exercises from my Management Information Systems studies (Python and SQL).

- employee_directory_report.ipynb, inventory_and_low_stock_report.ipynb, json_to_excel_reports_1.ipynb - Python notebooks that read JSON data and build formatted Excel reports with openpyxl (inventory, sales, support and employee reports, low-stock alerts).
- northwind_1.sql to northwind_10.sql - SQL queries on the Northwind database: filtering, JOINs, GROUP BY, aggregate functions and date functions.
- move_zeros.ipynb, sum_rec.ipynb, sum_even.ipynb, sum_even_indices.ipynb - small Python exercises: lists, loops, recursion.
Tools: Python, openpyxl, JSON, SQL (Northwind).
