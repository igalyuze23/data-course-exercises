# Data Course Exercises

Exercises from my Management Information Systems studies (Python and SQL).

- `python-excel-reports/` - Python notebooks that read JSON data and build formatted Excel reports with openpyxl (inventory, sales, support and employee reports, low-stock alerts).
- `sql-northwind/` - SQL queries on the Northwind database: filtering, JOINs, GROUP BY, aggregate functions and date functions.
- `python-basics/` - small Python exercises: lists, loops, recursion.

Tools: Python, openpyxl, JSON, SQL (Northwind).
